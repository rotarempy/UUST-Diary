# УУНиТ Дневник · UUST Diary

## Возможности

- Расписание выбранной группы: недели, время занятий, преподаватели и аудитории.
- Цвета пар по типу: лекции — синие, практики — жёлтые, лабораторные — фиолетовые, остальные — зелёные.
- Лекции, домашние задания и экзамены с привязкой к конкретной паре.
- Markdown, предпросмотр текста, изображения, PDF и другие вложения.
- Автосохранение черновиков и просмотр лекций по предметам.
- Календарь домашних заданий и экзаменов, отметки выполненных ДЗ.
- Локальное хранение записей, резервные копии JSON и очистка данных.
- Передача данных между приложениями на ПК и Android с автоматическим обнаружением устройств.
- Экспорт сохранённого расписания для веб-версии на GitHub Pages без бэкенда.
- Шесть тем, светлый и тёмный режимы, масштаб интерфейса и мобильное отображение.

## Как пользоваться

### Расписание и выбор группы

Начните вводить название группы в поле сверху и выберите её из списка. Выбранная группа сохраняется между запусками. Стрелки переключают недели, кнопка **«Сегодня»** возвращает к текущей неделе. На телефоне выберите нужный день в строке над списком пар; на ПК расписание отображается таблицей.

В карточке пары показаны название предмета, время, тип занятия, преподаватель и аудитория, если эти сведения есть в источнике. Цвет помогает различать занятия:

| Тип пары | Цвет |
| --- | --- |
| Лекция | Синий |
| Практика или семинар | Жёлтый |
| Лабораторная работа | Фиолетовый |
| Другой или неуказанный тип | Зелёный |

Приложения на ПК и Android загружают и разбирают расписание с сайта университета. Загруженные недели сохраняются на устройстве и доступны без повторного запроса. При ошибке загрузки можно воспользоваться кнопкой **«Повторить загрузку»**.

Веб-версия читает только опубликованные файлы своего сайта. Она не подключается к сайту университета и не требует сервера для парсинга. Обновление её расписания описано ниже.

### Лекции и просмотр по предметам

Нажмите на пару в расписании и выберите **«Лекция»**. Введите название, текст и при необходимости добавьте вложения, затем нажмите **«Сохранить»**.

Открыть запись можно через ту же пару или вкладку **«Лекции по предметам»**. В этой вкладке записи и черновики лекций сгруппированы по дисциплинам. В сохранённой записи доступны **«Редактировать»** и **«Удалить»**; удаление требует подтверждения.

### Домашние задания

Откройте пару и выберите **«ДЗ»**. Добавьте текст задания и файлы, затем сохраните запись. В просмотре задания нажмите **«Сделано»**, чтобы отметить выполнение; кнопка **«Не сделано»** снимает отметку.

Задание связано с выбранной парой и отображается в календаре на её дату. Состояние выполнения также видно на карточке пары.

### Экзамены

Откройте пару и выберите **«Экзамен»**. Укажите название, добавьте вопросы, заметки или файлы и нажмите **«Сохранить»**. Запись появится в календаре на дату выбранной пары. Через просмотр её можно отредактировать или удалить.

### Текст, Markdown и вложения

В редакторах лекции, ДЗ и экзамена можно использовать обычный текст и Markdown: заголовки, выделение, списки, таблицы, ссылки и блоки кода. Поддерживаются разрешённые HTML-теги; исполняемый код удаляется при отображении. Разверните **«Предпросмотр»**, чтобы увидеть оформление до сохранения.

Нажмите **«Добавить файлы»** и выберите одно или несколько вложений. Изображения отображаются в записи, остальные файлы можно скачать. PDF просматривается внутри веб-интерфейса, а на Android открывается кнопкой **«Открыть PDF»**. Чтобы убрать вложение, откройте редактор и нажмите крестик рядом с файлом.

### Черновики и очистка редактора

Непустой черновик сохраняется автоматически при изменении текста и вложений. Можно закрыть редактор и продолжить работу позже: снова откройте соответствующий материал через пару, список лекций или календарь.

Кнопка **«Сохранить»** превращает черновик в сохранённую запись. Кнопка **«Очистить»** очищает содержимое редактора и его вложения; для удаления уже сохранённой записи используйте **«Удалить»** в режиме просмотра.

### Календарь

Откройте вкладку **«Календарь»**. Стрелки переключают месяцы, **«Сегодня»** возвращает к текущему месяцу. Нажмите на день, чтобы увидеть все его ДЗ и экзамены, затем выберите запись для просмотра или редактирования.

Календарь показывает выполненные задания и черновики. События привязаны к дате пары. Номера учебных недель берутся из расписания выбранной группы; если данных для даты нет, отображается прочерк.

### Темы и масштаб

Откройте настройки кнопкой с шестерёнкой. Выберите тему: **«Классическая»**, **«УУНиТ»**, **«Бумага»**, **«Кофе»**, **«Океан»** или **«Лес»**. Для каждой доступны светлый и тёмный режимы.

Ползунок меняет масштаб от **80% до 130%**. Кнопка **«Сбросить»** возвращает 100%. Выбранное оформление сохраняется на устройстве, а цвета типов пар учитывают светлый и тёмный режимы.

### Хранение, экспорт и импорт записей

Записи и вложения хранятся локально в приложении или браузере. Для резервной копии откройте **Настройки → Экспорт в JSON**. На ПК выберите место сохранения; на Android откроется системное окно сохранения или отправки; браузер скачает файл.

Чтобы восстановить записи или перенести их вручную, выберите **«Импорт из JSON»**, укажите файл и подтвердите замену. Импорт заменяет текущие предметы, лекции, ДЗ, экзамены, черновики и выбранную группу данными из копии.

Этот JSON содержит личные записи и вложения, но не включает кэш расписания и настройки оформления. Для расписания предусмотрен отдельный экспорт, а для переноса всего содержимого между приложениями — синхронизация по локальной сети.

### Синхронизация между устройствами

Передача доступна между приложениями **ПК ↔ ПК**, **ПК ↔ Android** и **Android ↔ Android**.

1. Подключите устройства к одной локальной сети и откройте настройки приложения на обоих.
2. В блоке **«Устройства в локальной сети»** автоматически появятся другие доступные экземпляры UUST Diary. Своё устройство в список не включается; адреса и коды вводить не нужно.
3. Сравните количество записей: ваше показано над списком, количество на другом устройстве — рядом с его именем.
4. Нажмите на устройство, которому хотите отправить данные.
5. На получателе подтвердите запрос. Только после согласия начнётся передача записей и вложений.
6. Дождитесь сообщения о принятии данных на устройстве отправителя.

Передача **полностью заменяет** записи, черновики, сохранённое расписание, выбранную группу и оформление получателя. Данные двух устройств не объединяются. В счётчик входят лекции, ДЗ, экзамены и черновики; предметы, пары расписания и вложения передаются, но не увеличивают счётчик.

В списке видны только устройства с открытыми настройками UUST Diary. При закрытии настроек или уходе приложения в фон обнаружение отключается. Если список пуст, нажмите **«Обновить список»**, проверьте подключение к одной сети и разрешение приложения в брандмауэре. Гостевая Wi-Fi сеть может блокировать связь между устройствами.

Веб-версия не участвует в этом обмене. Для локальной передачи используйте доверенную сеть: соединение не шифруется.

### Экспорт расписания и обновление веб-версии

В настройках нажмите **«Скачать данные расписания»**. Приложение соберёт все сохранённые группы и недели в файл `snapshot.json`. Экспорт включает только уже сохранённое расписание и не загружает недостающие недели. Личные записи и вложения в этот файл не попадают.

| Где выполняется экспорт | Куда сохраняется файл |
| --- | --- |
| Приложение на ПК | В выбранную папку под именем `snapshot.json` |
| Приложение на Android | `Documents/UUST-Diary/schedule/snapshot.json` |
| Веб-версия | Через стандартную загрузку файла браузером |

Чтобы обновить расписание на GitHub Pages:

1. В приложении загрузите нужные группы и недели, затем экспортируйте расписание.
2. Поместите файл в репозиторий по пути **`docs/data/schedule/snapshot.json`**. При экспорте на ПК можно сразу выбрать папку `docs/data/schedule`.
3. Отправьте изменения в GitHub и дождитесь публикации сайта из папки `docs`.
4. Перезагрузите веб-версию — JSON станет основным источником расписания.

Если `snapshot.json` ещё не опубликован, веб-версия использует имеющиеся локальные HTML-файлы из `docs/data/schedule/`.

### Очистка всех данных

Откройте **Настройки → Очистить все данные приложения** и подтвердите действие. Будут удалены локальные записи, вложения, черновики, выбранная группа, сохранённое расписание и настройки оформления. Затем приложение перезагрузится.

Очистка действует только на текущее приложение или браузер. Экспортированные файлы, содержимое других устройств и опубликованное на GitHub расписание сохраняются.

## На чём работает

| Часть проекта | Технологии |
| --- | --- |
| Общий интерфейс | HTML, CSS и JavaScript; адаптивное отображение для ПК и телефона |
| Веб-версия | Статические файлы из `docs/`; GitHub Pages или другой статический хостинг |
| Приложение для ПК | Electron; упаковка через electron-builder для Windows, Linux и macOS |
| Приложение для Android | Capacitor 8, Java, Android SDK и Gradle |
| Локальные данные | IndexedDB для записей и вложений; localStorage для настроек и кэша расписания |
| Форматирование текста | Marked и обработка разрешённых HTML-тегов |
| Синхронизация | UDP multicast для обнаружения, локальный HTTP для передачи после подтверждения |
| Общая сборка | Node.js 24+, npm и esbuild; интерфейс из `docs/` собирается в `www/` |
| Вспомогательные инструменты | Python для локального сервера и загрузки HTML-копий расписания |
| Проверки | Node.js Test Runner, jsdom, fake-indexeddb и Python unittest; GitHub Actions для тестов и сборок |

## Структура репозитория

| Путь | Назначение |
| --- | --- |
| `.github/workflows/` | Автоматические тесты и сборки Windows / Android |
| `docs/index.html` | Основная страница общего интерфейса |
| `docs/css/` | Стили, темы, мобильная версия и календарь |
| `docs/js/` | Расписание, редакторы, хранение, календарь, настройки, экспорт и интерфейс синхронизации |
| `docs/data/schedule/` | Опубликованные HTML-копии расписания; сюда добавляется экспортированный `snapshot.json` |
| `docs/vendor/` | Локальная копия библиотеки Marked и её лицензия |
| `desktop/` | Оболочка Electron, доступ к источнику расписания и обмен по локальной сети |
| `native/platform.js` | Общий мост между интерфейсом и возможностями ПК / Android |
| `android/` | Android-проект, Gradle Wrapper, ресурсы и конфигурация приложения |
| `android/app/src/main/java/ru/uust/lectures/` | Главная Android-активность и плагин локальной синхронизации |
| `assets/` | Иконки приложения для сборок |
| `scripts/` | Сборка общего интерфейса, Android-команды и обновление HTML-расписания |
| `tests/` | Проверки интерфейса, хранения, парсера, синхронизации и локального сервера |
| `serve.py` | Локальный сервер для разработки веб-версии |
| `package.json`, `package-lock.json` | Команды проекта и зависимости Node.js |
| `capacitor.config.json` | Настройки оболочки Capacitor |
| `requirements.txt` | Зависимости Python-инструментов |
| `BUILD-WINDOWS.bat`, `BUILD-ANDROID.bat` | Команды сборки для запуска из Windows |
| `UPDATE-SCHEDULE.bat` | Запуск обновления HTML-копий расписания |
| `INSTRUCTION-RU.md` | Дополнительная инструкция по публикации расписания |
| `VALIDATION.md` | Исторический отчёт о проверках проекта |
| `.gitignore`, `.gitattributes` | Правила исключения файлов из Git и обработки текстовых файлов |

`www/`, `node_modules/`, `release/` и Android-каталоги сборки создаются локально и не входят в исходники репозитория. Основной интерфейс редактируется в `docs/`.
