# UUST Diary: ручное обновление расписания для GitHub Pages

Это временная схема без GitHub Actions и прокси: Python на вашем ПК скачивает общедоступное расписание УУНиТ и сохраняет HTML-снимки в `docs/data/schedule/`. Сайт читает их статически через GET.

## Установка

1. Распакуйте архив в корень `C:\IT\Lectures` **с заменой**. Файл `.github/workflows/update-schedule.yml` в этом архиве отсутствует и не нужен.
2. Убедитесь, что Python 3 установлен и команда `py -3 --version` работает.
3. Дважды нажмите `UPDATE-SCHEDULE.bat` или выполните `py -3 scripts\update-pages-schedule.py --batch 80` из корня проекта. Скрипт сначала скачает список групп и обработает до 80 групп, сохраняя курсор для следующего запуска. На первое обновление уйдёт некоторое время; для большего охвата запускайте повторно. Группа с ID `14380` при наличии в списке обрабатывается первой, но это не гарантия, что она вам нужна.
4. Проверьте наличие `docs\data\schedule\groups.html`, а также файлов `groups\<ID>.html` и `weeks\<ID>\<N>.html` для нужной группы. Если есть ошибки, посмотрите журнал и повторите запуск.
5. Выполните `git add docs scripts/update-pages-schedule.py UPDATE-SCHEDULE.bat INSTRUCTION-RU.md && git commit -m "Publish static UUST schedule" && git push origin main`.
6. Дождитесь успешного GitHub Pages deploy. Откройте `https://rotarempy.github.io/UUST-Diary/data/schedule/groups.html`, затем проверьте нужную группу и текущую неделю **в приватном окне** на самом сайте.

## Ограничения

- Данные обновляются только при ручном запуске скрипта и публикации коммита.
- По умолчанию за один запуск обрабатывается 80 групп; для всех групп потребуется много запусков, либо увеличьте `--batch` (не создавайте чрезмерную нагрузку на источник).
- Скрипт выгружает только недели около текущей даты. Другие недели могут быть недоступны.
- Не загружайте на GitHub личные резервные копии, токены или `.env`.
- Если вы уже сделали `git revert`, это нормально: данный архив заново применяет только файлы для статического режима, без GitHub Actions.
- Перед публикацией убедитесь, что данные являются общедоступным расписанием, а не личными данными студентов.
