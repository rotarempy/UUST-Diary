Устройства в локальной сети

Откройте настройки приложения на обоих устройствах. Нажмите на устройство, чтобы отправить ему все данные. Получатель должен подтвердить замену своих данных.

В списке только устройства с открытыми настройками UUST Diary. При закрытии настроек обнаружение выключается. Используйте доверенную сеть.

Данные
Автосохранение работает локально в этом браузере. Данные не синхронизируются между устройствами и могут быть потеряны при очистке данных приложения или браузера — регулярно экспортируйте резервную копию JSON. Импорт полностью заменяет текущие данные содержимым выбранного файла. Чтобы перенести данные на другое устройство, экспортируйте файл и импортируйте его там.
