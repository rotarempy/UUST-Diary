# UUST Diary — расписание на GitHub Pages

1. Скопируйте файлы из архива **в корень проекта**, сохранив структуру папок.
2. Выполните `git add docs/js/schedule-config.js docs/js/uust-official-client.js scripts/update-pages-schedule.py .github/workflows/update-schedule.yml GITHUB-PAGES-SETUP.md` и закоммитьте изменения.
3. Отправьте их через `git push origin main`.
4. В GitHub откройте **Settings → Actions → General → Workflow permissions**; разрешите `Read and write permissions`, если это доступно. Workflow содержит `contents: write`; политики организации могут ограничить запись.
5. В **Actions → Update Pages Schedule → Run workflow** запустите обновление вручную. Первый запуск наполнит данными около 80 групп. Повторные запуски обрабатывают следующие группы; при ~787 группах полный цикл займёт около 10 запусков (~30 часов при запуске раз в 3 часа).
6. Настройка **Settings → Pages → Deploy from a branch → main /docs** уже подходит. После публикации проверьте `https://rotarempy.github.io/UUST-Diary/data/schedule/groups.html` и откройте расписание.

## Важно

- Web-версия использует статические GET файлы; Windows, Android и локальный Python-прокси по-прежнему используют прежние запросы POST.
- Обновляется текущая и соседние недели каждой обработанной группы. Далёкие прошлые и будущие недели появятся только когда входят в окно обновления, либо если уже загружались ранее. Без данных соответствующей недели приложение покажет понятное сообщение.
- GitHub Actions не может сформировать расписание новой группы *по запросу* посетителя. При отсутствии её снимка нужно дождаться очереди обработки.
- Если сайт УУНиТ изменит HTML, выгрузка может перестать работать — смотрите логи Actions. Сбои отдельных групп фиксируются в `docs/data/schedule/state.json`.
- Сервис не официальен; данные публично доступны в репозитории. Не добавляйте персональные сведения, пароли или токены.
- Скрипт использует стандартный Python и проверяет TLS. Источник должен быть доступен с GitHub Actions. В этом окружении реальную доступность источника с GitHub не проверяли.
