# Проверка проекта, 13 октября 2026

Успешно выполнено:

- Установка закреплённых npm-зависимостей; package-lock.json соответствует package.json.
- Сборка общего www из docs через esbuild, включая мост Capacitor/Electron.
- Создание и синхронизация Android-проекта Capacitor: App, Filesystem, Share, FileViewer.
- 4 проверки нативной прослойки: фиксированный источник и точные формы POST,
  передача ответа/статуса, отмена запроса, экспорт, порядок подключения моста.
- DOM-интеграция полного общего интерфейса, включая кеш недель, редактор,
  вложения, JSON, темы, масштаб и повторные открытия.
- 8 тестов парсера/клиента/тем: календарь, кеш, расписание, 12 палитр,
  контраст, сохранение/миграция настроек и светлая УУНиТ по умолчанию.
- Наличие Gradle wrapper, основного Activity и зарегистрированных плагинов.
- Проверка синтаксиса Electron main.

Не выполнено:

- Gradle-сборка APK: запуск java в этой среде завершается ошибкой
  загрузки libjli.so; Android SDK также не установлен.
- Сборка/запуск Windows EXE: в этой среде нет Windows и установленного
  Electron runtime. В проекте подготовлен electron-builder и Windows workflow.
- Запуск на реальном телефоне/ПК и живая загрузка расписания нативным транспортом.
- GitHub workflow подготовлен, но не опубликован и не запускался.

Архив содержит исходники и рабочую сборку общего интерфейса, а не готовые APK/EXE.
Локальная сборка и автоматическая сборка описаны в README.md.
